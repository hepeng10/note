# vscode
## 不删除return后的代码
保存时会自动删除 return 后的代码，是 vscode 配置默认行为，需要修改配置文件：
```json
    "editor.codeActionsOnSave": {
        "source.fixAll": "never", // 禁用所有的，默认值是 explicit
        "source.fixAll.eslint": "explicit", // 启用 eslint
        "source.fixAll.stylelint": "explicit" // 启用 stylelint
    },
```
## 资源管理器不随文件跳转
在 vscode 中，资源管理器默认会随着你在编辑器中跳转到不同的文件而自动展开并定位到当前文件的位置。如果你不希望资源管理器自动跳转，可以通过以下步骤进行设置：
1. 打开 vscode 设置：ctrl + ,
2. 搜索“Auto Reveal”
3. 将其设置为“false”

如果想在资源管理器中定位到当前文件，那么可以配置快捷键：
1. crl + shift + p 搜索活动文件，点击绑定快捷键：
    ![图 0](assets/1777338186684.png)  
2. 可以绑定快捷键为“shift + alt + e”
