# 数组对象的修改
在使用数组对象时，如果需要修改数组对象的属性，需要使用 `@Trace` 注解。只使用`@Local`直接创建数组对象，修改某个对象中的数据时，页面不会更新。
```ts
// 使用 @ObservedV2 装饰class，这个class就是数组中某一项的数据
@ObservedV2
class DeviceItem {
  deviceId: string = ''
  name: string = ''
  RSSI: number = 0;
  @Trace connected: boolean = false; // 使用 @Trace 注解，这个属性会在数组中更新时，自动触发页面更新
  MAC: string = ''
  constructor(deviceId: string, name: string, RSSI: number, connected: boolean, MAC: string) {
    this.deviceId = deviceId
    this.name = name
    this.RSSI = RSSI
    this.connected = connected
    this.MAC = MAC
  }
}



@ComponentV2
export struct Scan {
  @Local test: boolean = true;
  @Local isScanning: boolean = false;
  @Local isConnecting: boolean = false;
  @Local connectedDeviceId: string = '';
  // 在页面中使用上面的 class 来创建数组对象，直接修改其中的 connected 属性，页面会自动更新
  @Local deviceList: BluetoothDevice[] = [
    new DeviceItem('BMS-001', 'BMS-001', -45, false, 'ABCDEF'),
    new DeviceItem('BMS-002', 'BMS-002', -68, false, 'BCDEF'),
    new DeviceItem('BMS-003', 'BMS-003', -68, false, 'BCDEF'),
    new DeviceItem('BMS-004', 'BMS-004', -68, false, 'BCDEF'),
    new DeviceItem('BMS-005', 'BMS-005', -68, false, 'BCDEF'),
    new DeviceItem('BMS-006', 'BMS-006', -68, false, 'BCDEF'),
    new DeviceItem('BMS-007', 'BMS-007', -68, false, 'BCDEF'),
    new DeviceItem('BMS-008', 'BMS-008', -68, false, 'BCDEF'),
  ];
  ...
}
```

# 阴影被裁剪
如在一个容器里放了个卡片组件，卡片组件有阴影效果，但是会出现阴影被裁剪导致看不到的情况。此时需要在容器上加上`clip(false)`来关闭裁剪。
```ts
// 总电压和总电流
Grid() {
  GridItem() {
    CardContainer() {
      BatteryInfoCard({
        icon: $r('app.media.carbon_lightning'),
        iconColor: '#eab308',
        title: '总电压',
        value: this.totalVoltage,
        unit: 'V'
      })
    }
  }

  GridItem() {
    CardContainer() {
      BatteryInfoCard({
        icon: $r('app.media.carbon_activity'),
        iconColor: '#3b82f6',
        title: '总电流',
        value: this.totalCurrent,
        unit: 'A',
        subValue: this.currentStatus,
        subValueColor: this.currentStatus === '充电中' ? '#ef4444' : '#22c55e'
      })
    }
  }
}
.width('100%')
.columnsTemplate('1fr 1fr') // 设置每个GridItem占的比例
.columnsGap(12) // 设置列间距
.clip(false) // 关闭裁剪，解决阴影被裁剪的问题
```

# ForEach 渲染不更新
使用 ForEach 渲染字符串或数值数组时，如果使用 index 作为唯一ID，会导致修改数组中的数据时，页面不会更新。如果使用字符串/数值作为唯一ID，如果有两个相同的值只会渲染一个。所以应该不设置id，会自动使用默认的`(item, index) => index + '__' + JSON.stringify(item)`，就能保证每个元素都有唯一ID，页面就能正确更新。

# @Event 默认值
使用@Event时，如果没有设置默认值，父组件也没有传值时，@Event装饰的函数也是有个空函数的。因此就会导致如果父组件没有传值，子组件通过判断@Event装饰的函数是否有值时就始终为true，因此需要手动将@Event装饰的函数值设置为undefined。
```ts
  // 这两种写法，onHideEvent都有默认值
  @Event onHideEvent?: () => boolean
  @Event onHideEvent: () => boolean
  
  // 这样写，父组件没传时，判断是否有值时才为false
  @Event onHideEvent?: () => boolean = undefined
```

# TextInput 输入校验和限制
在使用TextInput时，要对输入进行校验和限制输入内容，有着和uniapp同样的问题。所以需要先给state赋值为输入的新值，然后校验限制后，再将校验后的值赋值给state，才能正常渲染。不过鸿蒙里没有`nextTick`，所以需要使用`setTimeout(() => {}, 100)`来模拟`nextTick`的效果。
另一个方法是使用`.onWillChange()`来限制，返回一个布尔值，来决定当次输入是否有效。这个方式不会出现输入内容闪烁的问题，但是对于复杂的校验还是没有onChange灵活。
如果只是很简单的限制，也可以使用`.inputFilter()`，只能使用正则表达式来限制输入内容。
