# 使用tailwindcss
按照 https://umijs.org/docs/max/tailwindcss，复制Max项目的代码到项目终端运行，然后再执行下`npm install`，安装依赖。

# 国际化
config.ts 中的国际化相关配置不能直接注释，否则会导致项目启动失败。报错 useIntl 找不到。
可运行`npm run i18n-remove`，删除国际化相关配置。（不知道是不是已经改了代码，导致脚本清除相关代码不彻底，还是脚本本来就有问题，反正脚本运行后有点问题，如果要去除国际化最好项目一开始就去除，并且使用git仔细检查修改的文件是否有问题。性能影响不大，直接屏蔽语言切换按钮也行。）
