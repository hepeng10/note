# vscode
### 点击跳转
import 的包 ctrl + 点击 后会在浏览器打开go官网，可以通过设置修改此问题。
1. ctrl+, 打开设置
2. 搜索 gopls。这里注意要在 vscode 打开的项目启动了 go 相关扩展才能搜出此项配置，扩展禁用了的项目中进行搜索是搜不出来的。
3. 点击 在settings.json中编辑，添加以下配置：
```json
{
    "gopls": {
        // 添加此配置即可
        "ui.navigation.importShortcut": "Definition"
    }
}
```
