go的网络通信可通过标准库的`net`包实现。
### 一、TCP编程（底层字节流通信）
#### 核心概念
TCP是**面向连接、可靠的字节流传输协议**，是HTTP/RPC/WebSocket的底层基础。Go通过`net`包实现TCP通信，适用于需要自定义协议、高可靠的场景（如游戏、即时通信、物联网）。

#### 示例：TCP服务端 + 客户端
##### 1. TCP服务端（tcp_server.go）
```go
package main

import (
	"bufio"
	"fmt"
	"net"
)

func main() {
	// 1. 监听TCP端口（:8888表示所有网卡监听8888端口）
	listener, err := net.Listen("tcp", ":8888")
	if err != nil {
		fmt.Printf("监听失败：%v\n", err)
		return
	}
	defer listener.Close() // 确保服务退出时关闭监听
	fmt.Println("TCP服务端启动，监听端口8888...")

	// 2. 循环接受客户端连接（阻塞）
	for {
		conn, err := listener.Accept()
		if err != nil {
			fmt.Printf("接受连接失败：%v\n", err)
			continue
		}
		// 3. 协程处理单个客户端（避免阻塞服务端）
		go handleClient(conn)
	}
}

// 处理单个客户端的读写逻辑
func handleClient(conn net.Conn) {
	defer conn.Close() // 客户端断开时关闭连接
	clientAddr := conn.RemoteAddr().String()
	fmt.Printf("客户端[%s]已连接\n", clientAddr)

	// 4. 循环读取客户端消息（按行读取，以\n分隔）
	reader := bufio.NewReader(conn)
	for {
		msg, err := reader.ReadString('\n')
		if err != nil {
			fmt.Printf("客户端[%s]断开连接：%v\n", clientAddr, err)
			break
		}
		fmt.Printf("收到[%s]消息：%s", clientAddr, msg)

		// 5. 回复客户端
		reply := fmt.Sprintf("服务端已收到：%s", msg)
		_, err = conn.Write([]byte(reply))
		if err != nil {
			fmt.Printf("回复[%s]失败：%v\n", clientAddr, err)
			break
		}
	}
}
```

##### 2. TCP客户端（tcp_client.go）
```go
package main

import (
	"bufio"
	"fmt"
	"net"
	"os"
)

func main() {
	// 1. 连接TCP服务端
	conn, err := net.Dial("tcp", "127.0.0.1:8888")
	if err != nil {
		fmt.Printf("连接服务端失败：%v\n", err)
		return
	}
	defer conn.Close()
	fmt.Println("已连接到TCP服务端，输入消息按回车发送（输入exit退出）：")

	// 2. 读取控制台输入
	reader := bufio.NewReader(os.Stdin)
	for {
		input, err := reader.ReadString('\n')
		if err != nil {
			fmt.Printf("读取输入失败：%v\n", err)
			break
		}
		// 输入exit退出
		if input == "exit\n" {
			fmt.Println("退出客户端")
			break
		}

		// 3. 发送消息到服务端
		_, err = conn.Write([]byte(input))
		if err != nil {
			fmt.Printf("发送失败：%v\n", err)
			break
		}

		// 4. 读取服务端回复
		reply, err := bufio.NewReader(conn).ReadString('\n')
		if err != nil {
			fmt.Printf("读取回复失败：%v\n", err)
			break
		}
		fmt.Printf("服务端回复：%s", reply)
	}
}
```

#### 关键知识点
- `net.Listen("tcp", addr)`：监听TCP端口，`addr`格式为`ip:port`（`:8888`等价于`0.0.0.0:8888`）；
- `listener.Accept()`：阻塞等待客户端连接，返回`net.Conn`（连接对象），每个连接需用协程处理；
- `net.Dial("tcp", addr)`：客户端发起TCP连接；
- `conn.Read/Write`：读写字节流，`bufio`封装可实现按行/按缓冲区读取，避免粘包问题（简单场景）。

### 二、HTTP编程（应用层协议）
#### 核心概念
HTTP是基于TCP的应用层协议，Go标准库`net/http`提供了**完整的HTTP服务端/客户端实现**，无需第三方库即可开发Web服务、RESTful API。

#### 示例：HTTP服务端 + 客户端
##### 1. HTTP服务端（http_server.go）
```go
package main

import (
	"fmt"
	"net/http"
	"strconv"
)

// 方式1：自定义处理器函数（处理/hello请求）
func helloHandler(w http.ResponseWriter, r *http.Request) {
	// 获取URL查询参数
	name := r.URL.Query().Get("name")
	if name == "" {
		name = "匿名用户"
	}
	// 写入HTTP响应
	fmt.Fprintf(w, "Hello %s! 这是HTTP服务端响应", name)
}

// 方式2：自定义结构体处理器（处理/add请求，需实现http.Handler接口）
type AddHandler struct{}

// 实现http.Handler的ServeHTTP方法
func (h *AddHandler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	aStr := r.URL.Query().Get("a")
	bStr := r.URL.Query().Get("b")
	a, _ := strconv.Atoi(aStr)
	b, _ := strconv.Atoi(bStr)
	fmt.Fprintf(w, "%d + %d = %d", a, b, a+b)
}

func main() {
	// 注册路由：函数处理器
	http.HandleFunc("/hello", helloHandler)
	// 注册路由：结构体处理器
	http.Handle("/add", &AddHandler{})

	// 启动HTTP服务（监听8080端口，nil使用默认多路复用器）
	fmt.Println("HTTP服务端启动，监听8080端口...")
	err := http.ListenAndServe(":8080", nil)
	if err != nil {
		fmt.Printf("服务启动失败：%v\n", err)
	}
}
```

##### 2. HTTP客户端（http_client.go）
```go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	// 1. 发送GET请求（快捷方式）
	resp, err := http.Get("http://127.0.0.1:8080/hello?name=张三")
	if err != nil {
		fmt.Printf("GET请求失败：%v\n", err)
		return
	}
	defer resp.Body.Close() // 必须关闭响应体，避免内存泄漏

	// 读取响应体
	body, err := io.ReadAll(resp.Body)
	if err != nil {
		fmt.Printf("读取响应失败：%v\n", err)
		return
	}
	fmt.Println("GET响应：", string(body))

	// 2. 发送POST请求（自定义请求）
	req, err := http.NewRequest("POST", "http://127.0.0.1:8080/add?a=10&b=20", nil)
	if err != nil {
		fmt.Printf("创建POST请求失败：%v\n", err)
		return
	}
	// 自定义客户端（可设置超时、代理等）
	client := &http.Client{}
	resp2, err := client.Do(req)
	if err != nil {
		fmt.Printf("POST请求失败：%v\n", err)
		return
	}
	defer resp2.Body.Close()
	body2, _ := io.ReadAll(resp2.Body)
	fmt.Println("POST响应：", string(body2))
}
```

#### 关键知识点
- `http.HandleFunc`：注册路由，绑定URL路径和处理器函数（签名`func(w http.ResponseWriter, r *http.Request)`）；
- `http.Handler`接口：自定义处理器需实现`ServeHTTP(w http.ResponseWriter, r *http.Request)`方法；
- `http.ListenAndServe`：启动HTTP服务，第二个参数为`nil`时使用默认的`http.DefaultServeMux`（多路复用器）；
- 客户端核心：`http.Get`/`http.Post`（快捷方式）、`http.NewRequest+client.Do`（自定义请求），响应体必须关闭；
- `r.URL.Query()`：获取URL查询参数，`r.FormValue()`：获取POST表单参数（自动解析）。

### 三、RPC编程（远程过程调用）
#### 核心概念
RPC（Remote Procedure Call）是“远程过程调用”，允许程序调用另一台机器上的函数/方法，就像调用本地函数一样。Go标准库`net/rpc`基于TCP实现RPC，支持GOB（二进制）/JSON编码。

#### 示例：RPC服务端 + 客户端
##### 1. RPC服务端（rpc_server.go）
```go
package main

import (
	"fmt"
	"net"
	"net/rpc"
)

// 1. 定义RPC服务结构体（必须导出，首字母大写）
type MathService struct{}

// 2. 定义RPC方法入参（必须导出）
type Args struct {
	A, B int
}

// 3. 定义RPC方法（必须满足：导出方法、2个入参、第2个入参是指针、返回error）
// 加法方法
func (m *MathService) Add(args Args, reply *int) error {
	*reply = args.A + args.B
	return nil
}

// 乘法方法
func (m *MathService) Multiply(args Args, reply *int) error {
	*reply = args.A * args.B
	return nil
}

func main() {
	// 4. 注册RPC服务（将MathService注册为"Math"服务）
	err := rpc.RegisterName("Math", &MathService{})
	if err != nil {
		fmt.Printf("注册服务失败：%v\n", err)
		return
	}

	// 5. 监听TCP端口
	listener, err := net.Listen("tcp", ":9999")
	if err != nil {
		fmt.Printf("监听失败：%v\n", err)
		return
	}
	defer listener.Close()
	fmt.Println("RPC服务端启动，监听9999端口...")

	// 6. 循环处理客户端连接
	for {
		conn, err := listener.Accept()
		if err != nil {
			fmt.Printf("接受连接失败：%v\n", err)
			continue
		}
		// 协程处理，使用默认GOB编码（高效二进制）
		go rpc.ServeConn(conn)
	}
}
```

##### 2. RPC客户端（rpc_client.go）
```go
package main

import (
	"fmt"
	"net/rpc"
)

// 必须和服务端定义一致
type Args struct {
	A, B int
}

func main() {
	// 1. 连接RPC服务端
	client, err := rpc.Dial("tcp", "127.0.0.1:9999")
	if err != nil {
		fmt.Printf("连接RPC服务端失败：%v\n", err)
		return
	}
	defer client.Close()

	// 2. 调用远程方法：Math.Add
	var reply int
	err = client.Call("Math.Add", Args{A: 10, B: 20}, &reply)
	if err != nil {
		fmt.Printf("调用Add失败：%v\n", err)
		return
	}
	fmt.Println("10 + 20 =", reply)

	// 3. 调用远程方法：Math.Multiply
	err = client.Call("Math.Multiply", Args{A: 10, B: 20}, &reply)
	if err != nil {
		fmt.Printf("调用Multiply失败：%v\n", err)
		return
	}
	fmt.Println("10 * 20 =", reply)
}
```

#### 关键知识点
- RPC方法严格规则：导出方法（首字母大写）、2个入参（都导出）、第2个入参是指针、返回值为`error`；
- `rpc.RegisterName`：给服务起别名（如"Math"），客户端通过“服务名.方法名”调用；
- `rpc.ServeConn`：处理客户端连接，默认GOB编码，也可使用JSON编码（`rpc.ServeCodec(rpc.NewJSONCodec(conn))`）；
- 客户端`client.Call("服务名.方法名", 入参, 出参指针)`：出参必须是指针，接收远程方法的返回结果。

### 四、WebSocket编程（双向实时通信）
#### 核心概念
WebSocket是基于TCP的**全双工通信协议**，允许服务端主动向客户端推送数据，适用于实时通信（如聊天、弹幕、实时监控）。Go标准库无原生实现，常用第三方库`gorilla/websocket`。

#### 前置：安装依赖
```bash
go get github.com/gorilla/websocket
```

#### 示例：WebSocket服务端 + 客户端
##### 1. WebSocket服务端（ws_server.go）
```go
package main

import (
	"fmt"
	"net/http"

	"github.com/gorilla/websocket"
)

// 升级器：将HTTP连接升级为WebSocket
var upgrader = websocket.Upgrader{
	CheckOrigin: func(r *http.Request) bool {
		return true // 允许所有跨域（生产环境需限制域名）
	},
}

// 客户端连接池 + 广播通道
var clients = make(map[*websocket.Conn]bool)
var broadcast = make(chan []byte)

// 处理WebSocket连接
func wsHandler(w http.ResponseWriter, r *http.Request) {
	// 1. 升级HTTP为WebSocket
	conn, err := upgrader.Upgrade(w, r, nil)
	if err != nil {
		fmt.Printf("升级失败：%v\n", err)
		return
	}
	defer conn.Close()

	// 2. 加入连接池
	clients[conn] = true
	fmt.Println("客户端连接，当前在线：", len(clients))

	// 3. 循环读取客户端消息
	for {
		// 读取文本消息（TextMessage）
		_, msg, err := conn.ReadMessage()
		if err != nil {
			fmt.Printf("客户端断开：%v\n", err)
			delete(clients, conn) // 移除连接
			break
		}
		fmt.Printf("收到消息：%s\n", msg)
		broadcast <- msg // 发送到广播通道
	}
}

// 广播消息到所有客户端
func broadcastMsg() {
	for {
		msg := <-broadcast
		// 遍历所有客户端发送
		for conn := range clients {
			err := conn.WriteMessage(websocket.TextMessage, msg)
			if err != nil {
				conn.Close()
				delete(clients, conn)
			}
		}
	}
}

func main() {
	// 启动广播协程
	go broadcastMsg()

	// 注册WebSocket路由（基于HTTP握手）
	http.HandleFunc("/ws", wsHandler)

	// 启动HTTP服务
	fmt.Println("WebSocket服务端启动，监听8080端口...")
	http.ListenAndServe(":8080", nil)
}
```

##### 2. WebSocket客户端（Go版，ws_client.go）
```go
package main

import (
	"bufio"
	"fmt"
	"os"

	"github.com/gorilla/websocket"
)

func main() {
	// 1. 连接WebSocket服务端
	conn, _, err := websocket.DefaultDialer.Dial("ws://127.0.0.1:8080/ws", nil)
	if err != nil {
		fmt.Printf("连接失败：%v\n", err)
		return
	}
	defer conn.Close()
	fmt.Println("已连接WebSocket，输入消息发送（exit退出）：")

	// 2. 协程读取服务端广播
	go func() {
		for {
			_, msg, err := conn.ReadMessage()
			if err != nil {
				fmt.Printf("读取失败：%v\n", err)
				return
			}
			fmt.Printf("\n收到广播：%s\n", msg)
		}
	}()

	// 3. 读取控制台输入并发送
	reader := bufio.NewReader(os.Stdin)
	for {
		input, err := reader.ReadString('\n')
		if err != nil || input == "exit\n" {
			fmt.Println("退出客户端")
			break
		}
		// 发送文本消息
		conn.WriteMessage(websocket.TextMessage, []byte(input))
	}
}
```

##### 3. WebSocket客户端（HTML版，浏览器测试）
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>WebSocket客户端</title>
</head>
<body>
    <input type="text" id="msgInput" placeholder="输入消息">
    <button onclick="sendMsg()">发送</button>
    <div id="msgBox"></div>

    <script>
        // 连接WebSocket
        const ws = new WebSocket("ws://127.0.0.1:8080/ws");
        
        // 连接成功
        ws.onopen = () => appendMsg("系统：已连接服务端");
        
        // 接收消息
        ws.onmessage = (e) => appendMsg("服务端：" + e.data);
        
        // 发送消息
        function sendMsg() {
            const msg = document.getElementById("msgInput").value.trim();
            if (msg) {
                ws.send(msg);
                appendMsg("我：" + msg);
                document.getElementById("msgInput").value = "";
            }
        }
        
        // 追加消息到页面
        function appendMsg(msg) {
            document.getElementById("msgBox").innerHTML += `<p>${msg}</p>`;
        }
    </script>
</body>
</html>
```

#### 关键知识点
- WebSocket基于HTTP握手升级，需通过`Upgrader`完成；
- `CheckOrigin`：跨域检查，生产环境需指定允许的域名（如`return r.Header.Get("Origin") == "http://localhost:8080"`）；
- 核心方法：`ReadMessage()`（读）、`WriteMessage()`（写），支持文本（`TextMessage`）和二进制（`BinaryMessage`）；
- 广播实现：通过通道+协程，将单个客户端消息转发给所有在线客户端；
- 浏览器端：使用原生`WebSocket`对象，API和Go客户端一致（`onopen`/`onmessage`/`send`）。

### 总结
| 通信方式 | 核心包/库                | 核心特点                  | 适用场景                     |
|----------|--------------------------|---------------------------|------------------------------|
| TCP      | `net`                    | 底层字节流、可靠、面向连接 | 自定义协议、游戏、IM、物联网 |
| HTTP     | `net/http`               | 应用层协议、简单易用      | Web服务、RESTful API         |
| RPC      | `net/rpc`                | 远程函数调用、像调用本地  | 微服务间通信、跨服务调用     |
| WebSocket| `gorilla/websocket`      | 全双工、实时双向通信      | 聊天、弹幕、实时监控         |

#### 关键注意事项
1. TCP/RPC/WebSocket需用协程处理多客户端，避免服务端阻塞；
2. HTTP响应体必须关闭（`defer resp.Body.Close()`），否则泄漏文件句柄；
3. RPC方法必须满足严格的签名规则，否则注册/调用失败；
4. WebSocket生产环境需限制跨域，避免恶意连接；
5. 高并发场景下，TCP需处理粘包/拆包，HTTP可使用gin/echo等框架优化。
