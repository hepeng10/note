# 企业级框架
- GoFrame 类似于PHP的Laravel的web框架，适合做非微服务web项目。要开发物联网需要结合Paho。
- go-zero 注重微服务，相对简单，功能强大，但是灵活度较差，封装很深，适合用而不适合学习。
- Kratos 注重微服务，比go-zero更重，功能强大但复杂，适合高手阶段学习其架构设计。

# 技术选型
- Web：Gin
- ORM：GORM
- 缓存：go-redis
- 日志：zap
- 权限：jwt-go(JWT) + casbin(基于RBAC的权限控制)
- MQTT：Eclipse Paho MQTT Go Client。
    `Go程序 → MQTT客户端（Paho） → 连接EMQX → 订阅topic`
    `设备 → EMQX → Go服务（Paho） → Redis/MySQL → API（Gin / GoFrame）`
- 桌面软件：Wails。前端使用webkit所以可以方便的使用web技术栈，使用go调用系统API比electron更强大，比如做CAN通信的上位机要加载dll，go比nodejs好很多。
