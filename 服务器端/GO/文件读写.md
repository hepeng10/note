### 前置说明
Go文件操作主要依赖 `os` 包（核心）、`io/ioutil`（Go 1.16+已并入`os`/`io`）、`bufio`（缓冲读写）、`path/filepath`（路径处理）等包，所有demo都基于Go 1.18+版本编写，可直接复制运行。

---

## 场景1：基础操作 - 创建文件并写入内容
**用途**：新建文件（不存在则创建，存在则覆盖），写入字符串/字节数据。
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	// 1. 写入字符串（快捷方式：os.WriteFile，自动创建/覆盖文件，自动关闭文件）
	content := "Hello, Go文件操作！\n这是第一行内容\n这是第二行内容"
	// 参数：文件名、内容（转字节）、文件权限（0644：所有者读写，其他只读）
	err := os.WriteFile("demo1.txt", []byte(content), 0644)
	if err != nil {
		fmt.Printf("写入文件失败：%v\n", err)
		return
	}
	fmt.Println("demo1.txt 写入成功")

	// 2. 手动打开文件+写入（更灵活，支持多次写入）
	// os.OpenFile参数：文件名、打开模式、权限
	// 模式：O_CREATE(创建) | O_WRONLY(只写) | O_TRUNC(覆盖原有内容)
	file, err := os.OpenFile("demo1_manual.txt", os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0644)
	if err != nil {
		fmt.Printf("打开文件失败：%v\n", err)
		return
	}
	defer file.Close() // 必须关闭文件，defer保证函数退出时执行

	// 写入字节数据
	_, err = file.Write([]byte("手动写入第一行\n"))
	if err != nil {
		fmt.Printf("写入失败：%v\n", err)
		return
	}
	// 写入字符串（更友好）
	_, err = file.WriteString("手动写入第二行\n")
	if err != nil {
		fmt.Printf("写入字符串失败：%v\n", err)
		return
	}
	fmt.Println("demo1_manual.txt 手动写入成功")
}
```
**关键知识点**：
- `os.WriteFile` 是快捷方法，适合一次性写入，无需手动关闭文件；
- `os.OpenFile` 是通用打开文件的方法，`O_TRUNC` 会清空原有内容，若要追加需用 `O_APPEND`；
- 文件权限 `0644` 是八进制数，`0` 是前缀，`6`=读+写，`4`=只读。

## 场景2：读取文件 - 完整读取/按字节/按行
**用途**：读取文件内容，分3种常见方式（按需选择）。
```go
package main

import (
	"bufio"
	"fmt"
	"os"
)

func main() {
	// 方式1：完整读取（小文件推荐，一次性读入内存）
	content, err := os.ReadFile("demo1.txt")
	if err != nil {
		fmt.Printf("读取文件失败：%v\n", err)
		return
	}
	fmt.Println("=== 完整读取demo1.txt ===")
	fmt.Println(string(content))

	// 方式2：按字节读取（大文件，控制内存占用）
	file, err := os.Open("demo1.txt") // os.Open默认以只读模式打开
	if err != nil {
		fmt.Printf("打开文件失败：%v\n", err)
		return
	}
	defer file.Close()

	// 创建缓冲区（4KB，适合大文件）
	buf := make([]byte, 4096)
	fmt.Println("\n=== 按字节读取demo1.txt ===")
	for {
		n, err := file.Read(buf) // 读取到缓冲区，返回读取的字节数
		if n == 0 || err != nil {
			break // 读取完毕或出错，退出循环
		}
		fmt.Print(string(buf[:n])) // 只打印实际读取的字节
	}

	// 方式3：按行读取（文本文件，逐行处理）
	file, err = os.Open("demo1.txt") // 重新打开（指针已到文件末尾）
	if err != nil {
		fmt.Printf("打开文件失败：%v\n", err)
		return
	}
	defer file.Close()

	scanner := bufio.NewScanner(file) // 创建扫描器，按行读取
	fmt.Println("\n=== 按行读取demo1.txt ===")
	lineNum := 1
	for scanner.Scan() { // 逐行扫描，直到文件末尾
		line := scanner.Text() // 获取当前行内容
		fmt.Printf("第%d行：%s\n", lineNum, line)
		lineNum++
	}
	// 检查扫描过程中是否出错
	if err := scanner.Err(); err != nil {
		fmt.Printf("按行读取出错：%v\n", err)
	}
}
```
**关键知识点**：
- 小文件用 `os.ReadFile` 最简洁，大文件优先用 `按字节/按行` 读取，避免内存溢出；
- `bufio.Scanner` 是按行读取的最佳工具，自动处理换行符（\n/\r\n）；
- `os.Open` 以只读模式（`O_RDONLY`）打开文件，无法写入。

## 场景3：追加内容到文件
**用途**：在文件末尾添加内容（不覆盖原有内容）。
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	// 打开文件：O_APPEND(追加) | O_WRONLY(只写) | O_CREATE(不存在则创建)
	file, err := os.OpenFile("demo1.txt", os.O_APPEND|os.O_WRONLY|os.O_CREATE, 0644)
	if err != nil {
		fmt.Printf("打开文件失败：%v\n", err)
		return
	}
	defer file.Close()

	// 追加内容
	appendContent := "\n这是追加的内容1\n这是追加的内容2"
	_, err = file.WriteString(appendContent)
	if err != nil {
		fmt.Printf("追加内容失败：%v\n", err)
		return
	}
	fmt.Println("demo1.txt 追加内容成功")

	// 验证：读取文件查看结果
	content, _ := os.ReadFile("demo1.txt")
	fmt.Println("追加后文件内容：\n", string(content))
}
```
**关键知识点**：
- 核心是打开模式 `O_APPEND`，会将写入指针定位到文件末尾；
- 若文件不存在，`O_CREATE` 会创建新文件，追加逻辑依然生效。

## 场景4：获取文件信息（大小、权限、修改时间等）
**用途**：查询文件的元信息（大小、创建时间、是否为目录等）。
```go
package main

import (
	"fmt"
	"os"
	"time"
)

func main() {
	// 获取文件信息
	fileInfo, err := os.Stat("demo1.txt")
	if err != nil {
		fmt.Printf("获取文件信息失败：%v\n", err)
		return
	}

	fmt.Println("=== 文件元信息 ===")
	fmt.Printf("文件名：%s\n", fileInfo.Name())
	fmt.Printf("文件大小（字节）：%d\n", fileInfo.Size())
	fmt.Printf("是否为目录：%t\n", fileInfo.IsDir())
	fmt.Printf("权限：%s\n", fileInfo.Mode().String()) // 权限字符串（如-rw-r--r--）
	fmt.Printf("修改时间：%s\n", fileInfo.ModTime().Format(time.DateTime))

	// 判断文件是否存在（常用技巧）
	_, err = os.Stat("non_exist.txt")
	if os.IsNotExist(err) {
		fmt.Println("\nnon_exist.txt：文件不存在")
	} else if err != nil {
		fmt.Printf("判断文件存在性出错：%v\n", err)
	} else {
		fmt.Println("non_exist.txt：文件存在")
	}
}
```
**关键知识点**：
- `os.Stat()` 返回 `os.FileInfo` 接口，包含所有元信息；
- 判断文件是否存在：通过 `os.IsNotExist(err)` 检测（不要用 `err != nil` 直接判断，因为err可能是其他错误）。

## 场景5：目录操作（创建、遍历、判断类型）
**用途**：创建目录、遍历目录下的文件/子目录、判断路径是文件还是目录。
```go
package main

import (
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	// 1. 创建目录（单级）
	err := os.Mkdir("demo_dir", 0755) // 0755：所有者读写执行，其他读执行
	if err != nil && !os.IsExist(err) { // 忽略“目录已存在”的错误
		fmt.Printf("创建目录失败：%v\n", err)
		return
	}
	fmt.Println("demo_dir 创建成功（或已存在）")

	// 2. 创建多级目录（如 demo_dir/sub1/sub2）
	err = os.MkdirAll("demo_dir/sub1/sub2", 0755)
	if err != nil {
		fmt.Printf("创建多级目录失败：%v\n", err)
		return
	}
	fmt.Println("多级目录 demo_dir/sub1/sub2 创建成功")

	// 3. 遍历目录（递归遍历所有文件/子目录）
	fmt.Println("\n=== 遍历demo_dir目录 ===")
	err = filepath.Walk("demo_dir", func(path string, info os.FileInfo, err error) error {
		if err != nil {
			return err
		}
		// 区分文件/目录
		if info.IsDir() {
			fmt.Printf("[目录] %s\n", path)
		} else {
			fmt.Printf("[文件] %s （大小：%d字节）\n", path, info.Size())
		}
		return nil
	})
	if err != nil {
		fmt.Printf("遍历目录失败：%v\n", err)
	}

	// 4. 判断路径类型
	path := "demo_dir"
	info, _ := os.Stat(path)
	if info.IsDir() {
		fmt.Printf("\n%s 是目录\n", path)
	} else {
		fmt.Printf("\n%s 是文件\n", path)
	}
}
```
**关键知识点**：
- `os.Mkdir` 创建单级目录，`os.MkdirAll` 创建多级目录（推荐）；
- `filepath.Walk` 递归遍历目录，回调函数处理每个文件/目录；
- 目录权限 `0755`：`7`=读+写+执行（目录需要执行权限才能进入）。

## 场景6：文件复制（高效版，带缓冲区）
**用途**：复制文件（大文件推荐带缓冲区的方式，比一次性读写更高效）。
```go
package main

import (
	"bufio"
	"fmt"
	"io"
	"os"
)

// CopyFile 通用文件复制函数
func CopyFile(srcPath, dstPath string) error {
	// 打开源文件（只读）
	srcFile, err := os.Open(srcPath)
	if err != nil {
		return fmt.Errorf("打开源文件失败：%w", err)
	}
	defer srcFile.Close()

	// 创建目标文件（不存在则创建，存在则覆盖）
	dstFile, err := os.OpenFile(dstPath, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0644)
	if err != nil {
		return fmt.Errorf("创建目标文件失败：%w", err)
	}
	defer dstFile.Close()

	// 带缓冲区复制（4KB缓冲区，高效）
	bufReader := bufio.NewReader(srcFile)
	bufWriter := bufio.NewWriter(dstFile)
	defer bufWriter.Flush() // 刷新缓冲区，确保所有数据写入

	// 核心复制逻辑
	_, err = io.Copy(bufWriter, bufReader)
	if err != nil {
		return fmt.Errorf("复制文件失败：%w", err)
	}
	return nil
}

func main() {
	// 复制demo1.txt到demo1_copy.txt
	err := CopyFile("demo1.txt", "demo1_copy.txt")
	if err != nil {
		fmt.Printf("文件复制失败：%v\n", err)
		return
	}
	fmt.Println("文件复制成功！")

	// 验证：读取复制后的文件
	content, _ := os.ReadFile("demo1_copy.txt")
	fmt.Println("复制后的文件内容：\n", string(content))
}
```
**关键知识点**：
- `io.Copy` 是Go内置的高效复制函数，自动处理字节流；
- 缓冲区（`bufio.Reader/Writer`）减少系统调用次数，大文件复制必用；
- `bufWriter.Flush()` 必须调用，否则缓冲区剩余数据可能未写入文件。

## 场景7：文件移动/重命名、删除文件/目录
**用途**：重命名/移动文件、删除文件或目录。
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	// 1. 文件重命名（移动）
	// 若dstPath在不同目录，则是“移动”；同目录则是“重命名”
	err := os.Rename("demo1_copy.txt", "demo1_rename.txt")
	if err != nil {
		fmt.Printf("重命名文件失败：%v\n", err)
		return
	}
	fmt.Println("文件重命名为 demo1_rename.txt 成功")

	// 2. 删除文件
	err = os.Remove("demo1_rename.txt")
	if err != nil {
		fmt.Printf("删除文件失败：%v\n", err)
		return
	}
	fmt.Println("demo1_rename.txt 删除成功")

	// 3. 删除目录（空目录用os.Remove，非空用os.RemoveAll）
	err = os.Remove("demo_dir/sub1/sub2") // 删除空目录
	if err != nil {
		fmt.Printf("删除空目录失败：%v\n", err)
	} else {
		fmt.Println("demo_dir/sub1/sub2 删除成功")
	}

	// 删除非空目录（递归删除所有内容）
	err = os.RemoveAll("demo_dir")
	if err != nil {
		fmt.Printf("删除非空目录失败：%v\n", err)
	} else {
		fmt.Println("demo_dir 及其子目录删除成功")
	}
}
```
**关键知识点**：
- `os.Rename` 可实现重命名/移动，跨磁盘分区移动可能失败（需手动复制+删除）；
- `os.Remove` 只能删除空目录/文件，`os.RemoveAll` 递归删除非空目录（慎用！）。

## 场景8：二进制文件读写（结构体序列化/反序列化）
**用途**：将结构体数据写入二进制文件，或从二进制文件读取还原（适合存储结构化数据）。
```go
package main

import (
	"encoding/binary"
	"fmt"
	"os"
)

// User 定义要序列化的结构体
type User struct {
	ID   int32
	Age  int8
	Name [10]byte // 固定长度字符串（二进制需固定长度）
}

func main() {
	// 1. 写入二进制文件
	user := User{
		ID:   1001,
		Age:  25,
		Name: [10]byte{'Z', 'h', 'a', 'n', 'g', 'S', 'a', 'n'}, // 字符串转字节数组
	}

	file, err := os.OpenFile("user.bin", os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0644)
	if err != nil {
		fmt.Printf("打开二进制文件失败：%v\n", err)
		return
	}
	defer file.Close()

	// 序列化结构体到二进制（指定字节序：LittleEndian/BigEndian）
	err = binary.Write(file, binary.LittleEndian, &user)
	if err != nil {
		fmt.Printf("写入二进制文件失败：%v\n", err)
		return
	}
	fmt.Println("结构体写入二进制文件成功")

	// 2. 读取二进制文件还原结构体
	var readUser User
	file, err = os.Open("user.bin")
	if err != nil {
		fmt.Printf("打开二进制文件失败：%v\n", err)
		return
	}
	defer file.Close()

	// 反序列化二进制到结构体
	err = binary.Read(file, binary.LittleEndian, &readUser)
	if err != nil {
		fmt.Printf("读取二进制文件失败：%v\n", err)
		return
	}

	fmt.Println("\n=== 从二进制文件读取的结构体 ===")
	fmt.Printf("ID：%d\n", readUser.ID)
	fmt.Printf("Age：%d\n", readUser.Age)
	fmt.Printf("Name：%s\n", string(readUser.Name[:])) // 字节数组转字符串
}
```
**关键知识点**：
- 二进制读写需固定长度类型（如 `int32`/`[10]byte`），不能用 `string`/`slice`（长度不固定）；
- `binary.Write/Read` 需指定字节序（LittleEndian/大端，和平台无关）。

## 场景9：临时文件/临时目录操作
**用途**：创建临时文件/目录（程序退出后自动删除，适合临时存储数据）。
```go
package main

import (
	"fmt"
	"os"
	"path/filepath"
)

func main() {
	// 1. 创建临时目录
	tempDir, err := os.MkdirTemp("", "demo_temp_*") // 前缀为demo_temp_，后缀随机
	if err != nil {
		fmt.Printf("创建临时目录失败：%v\n", err)
		return
	}
	fmt.Printf("创建临时目录：%s\n", tempDir)

	// 2. 在临时目录创建临时文件
	tempFile, err := os.CreateTemp(tempDir, "demo_file_*.txt")
	if err != nil {
		fmt.Printf("创建临时文件失败：%v\n", err)
		return
	}
	fmt.Printf("创建临时文件：%s\n", tempFile.Name())

	// 写入临时文件
	_, err = tempFile.WriteString("临时文件内容")
	if err != nil {
		fmt.Printf("写入临时文件失败：%v\n", err)
		return
	}
	tempFile.Close() // 临时文件需手动关闭

	// 3. 读取临时文件
	content, err := os.ReadFile(tempFile.Name())
	if err != nil {
		fmt.Printf("读取临时文件失败：%v\n", err)
		return
	}
	fmt.Println("临时文件内容：", string(content))

	// 4. 手动清理临时文件/目录（可选，程序退出后系统会自动清理）
	err = os.RemoveAll(tempDir)
	if err != nil {
		fmt.Printf("清理临时目录失败：%v\n", err)
	} else {
		fmt.Println("临时目录已清理")
	}
}
```
**关键知识点**：
- `os.MkdirTemp`/`os.CreateTemp` 生成唯一的临时路径，避免冲突；
- 临时文件默认存储在系统临时目录（如Linux的 `/tmp`，Windows的 `%TEMP%`）；
- 建议手动清理临时文件（尤其是大量创建时），避免占用磁盘。

## 场景10：修改文件权限
**用途**：调整文件/目录的访问权限（如添加执行权限）。
```go
package main

import (
	"fmt"
	"os"
)

func main() {
	// 创建测试文件
	os.WriteFile("demo_perm.txt", []byte("测试权限"), 0644)

	// 1. 修改文件权限为 0755（所有者读写执行，其他读执行）
	err := os.Chmod("demo_perm.txt", 0755)
	if err != nil {
		fmt.Printf("修改权限失败：%v\n", err)
		return
	}
	fmt.Println("文件权限修改为 0755 成功")

	// 验证权限
	info, _ := os.Stat("demo_perm.txt")
	fmt.Printf("修改后权限：%s\n", info.Mode().String())

	// 2. 修改文件所有者（仅Linux/Mac有效，Windows需管理员权限）
	// err = os.Chown("demo_perm.txt", 1000, 1000) // uid=1000, gid=1000
	// if err != nil {
	// 	fmt.Printf("修改所有者失败：%v\n", err)
	// } else {
	// 	fmt.Println("文件所有者修改成功")
	// }

	// 清理文件
	os.Remove("demo_perm.txt")
}
```
**关键知识点**：
- `os.Chmod` 修改权限，八进制数表示（0644=rw-r--r--，0755=rwxr-xr-x）；
- `os.Chown` 修改所有者/所属组，仅类Unix系统有效，Windows不支持。

## 核心总结
1. **核心包**：`os`（基础操作）、`bufio`（缓冲读写）、`io`（流操作）、`filepath`（路径处理）；
2. **必做操作**：打开文件后必须用 `defer file.Close()` 关闭，避免文件句柄泄漏；
3. **错误处理**：文件操作的错误必须显式检查（如 `os.IsNotExist` 判断文件是否存在）；
4. **性能优化**：大文件读写用缓冲区（`bufio`），避免一次性读入内存；
5. **安全注意**：`os.RemoveAll` 慎用，避免误删重要文件；临时文件建议手动清理。
