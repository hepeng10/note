gin是go的一个轻量级web框架，对标的是express, koa这样的nodejs框架。
也有不少基于gin和其它库整合的脚手架，比如[nunu](https://go-nunu.github.io/nunu)，方便快速搭建项目。适合开发单体 / 轻量微服务项目。
字节的[CloudWeGo](https://www.cloudwego.io/zh/)项目开源了几个企业级微服务框架，不过不是基于gin的，自研框架，适合大型企业级微服务项目。

| 维度                | nunu                                  | CloudWeGo（字节）|
|---------------------|---------------------------------------|---------------------------------------|
| 定位                | 轻量应用开发脚手架（Scaffold）| 企业级微服务框架体系（Framework Suite） |
| 核心目标            | 快速开发单体/轻量微服务，降低组装成本 | 支撑高并发、分布式、大规模微服务集群，极致性能 |
| 核心组件            | 无自研核心组件，整合生态：<br>- Web：Gin<br>- ORM：gorm<br>- 配置：viper<br>- 日志：zap<br>- 工具：代码生成、配置管理 | 全自研核心组件（字节内部验证）：<br>- Hertz：高性能HTTP框架（对标Gin，性能更高）<br>- Kitex：高性能RPC框架（对标gRPC）<br>- Netpoll：自研高性能网络库<br>- Volcano：服务治理（注册发现、熔断降级）<br>- Sonic：高性能JSON编解码 |
| 设计哲学            | 「整合大于自研」，兼容生态，轻量无冗余 | 「自研核心组件」，极致性能，适配字节级分布式场景 |
| 性能                | 依赖Gin/gorm等基础库，性能等同于常规Go应用 | 自研网络库/编解码/协程模型，性能远超常规Go框架（Hertz比Gin高30%+，Kitex比gRPC高50%+） |
| 微服务能力          | 无原生微服务支持，需手动集成etcd/nacos | 内置完善微服务能力：服务注册发现、熔断降级、链路追踪、配置中心、流量控制 |
| 适用场景            | 1. 中小型单体Web应用<br>2. 轻量API服务<br>3. 快速原型开发<br>4. 新手入门Go项目 | 1. 大型分布式微服务集群<br>2. 高并发RPC服务（如电商、直播、云服务）<br>3. 企业级核心业务系统<br>4. 对性能/稳定性要求极高的场景 |
| 生态成熟度          | 小众脚手架，社区较小，更新频率一般    | 字节官方维护，社区活跃，文档完善，有大规模生产验证 |
| 学习成本            | 低（基于Gin/gorm等熟悉的库，只需学项目结构） | 高（需学习自研组件、微服务设计、分布式概念） |

## 安装gin
```go
go get -u github.com/gin-gonic/gin
```
其中`-u`参数表示如果已经安装了gin，就升级到最新版本。update。

## 基础API
gin的基础API如下：
```go
import (
    "github.com/gin-gonic/gin"
)

func main() {
    r := gin.Default()
    r.GET("/", func(c *gin.Context) {
        c.JSON(200, gin.H{
            "message": "Hello, world!",
        })
    })
    r.Run(":8080")
}
```
